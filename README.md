# Day 34 - Tailwind Task

Requirements: Tailwind configured with Vite/PostCSS; reusable Card component; responsive Flexbox navbar; button hover/focus/active states; variant/prop-based reusable styles.

## Run

```bash
npm install
npm run dev
```

## Verify

```bash
npm run build
```

Open the localhost URL shown by Vite. Resize to a mobile width to test the navbar. Click all buttons and check the message below.
